# Tools CI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give CI one environment per OS with every claimed tool installed, so the gated `*_shape.rs` tests run instead of skip, and a vanished package is a red step.

**Architecture:** A ghcr.io Docker image for Linux (`container:` keyword), idempotent setup scripts for Windows (choco + official zips) and macOS (brew + official tarballs), one new `tools.yml` workflow with an `image` job feeding a Linux container job plus Windows/macOS jobs, weekly cron as the rot detector.

**Tech Stack:** Docker/ghcr, GitHub Actions, apt, Chocolatey, Homebrew, pip.

**Spec:** `docs/superpowers/specs/2026-11-10-tools-ci-design.md`

## Global Constraints

- **No `Co-Authored-By` trailer** in any commit (user rule).
- Every tool claim in the scripts must trace to a registry check already performed (spec: per-OS table). No third-party setup actions.
- ghdl is always the official 6.0.0 line from ghdl/ghdl releases (the probed version); cocotb pinned `==2.1.0` (the probed version).
- pip installs use `python3 -m pip install --break-system-packages` (PEP 668 on Ubuntu 24.04; harmless where no marker exists).
- Per-OS promised sets (assertions must match exactly): Linux = ghdl nvc iverilog verilator yosys cocotb; Windows = ghdl iverilog yosys; macOS = ghdl iverilog verilator yosys cocotb.
- Honest local limits: no Docker or pwsh on this machine — Dockerfile and .ps1 get structural verification only; their first real proof is the CI run dispatched after merge (spec: Verification).

### Task 1: Linux Docker image

**Files:**
- Create: `.github/docker/linux.Dockerfile`

**Interfaces:**
- Produces: image `ghcr.io/nabilmerk/orbit-drives-ci-linux` consumed by Task 4's `linux` job via `container:`.

- [ ] **Step 1: Write the Dockerfile**

```dockerfile
FROM ubuntu:24.04

# git: actions/checkout needs it inside containers. curl: toolchain bootstrap.
# nvc/iverilog/verilator/yosys: all present in noble universe (checked 2026-11-10).
RUN apt-get update \
 && apt-get install -y --no-install-recommends \
      ca-certificates curl git \
      python3 python3-pip \
      nvc iverilog verilator yosys \
 && rm -rf /var/lib/apt/lists/*

# ghdl 6.0.0 — the official ubuntu24.04 build (the version the probed facts pin).
# Tarball layout is bin/ lib/ include/ at the root; /usr/local merges it onto PATH.
ARG GHDL_VERSION=6.0.0
RUN curl -fsSL -o /tmp/ghdl.tgz \
      "https://github.com/ghdl/ghdl/releases/download/v${GHDL_VERSION}/ghdl-mcode-${GHDL_VERSION}-ubuntu24.04-x86_64.tar.gz" \
 && tar -xzf /tmp/ghdl.tgz -C /usr/local \
 && rm /tmp/ghdl.tgz \
 && ghdl --version | head -1

# cocotb 2.1.0 — the probed runner version (cocotb_tools distribution).
RUN python3 -m pip install --break-system-packages cocotb==2.1.0 \
 && python3 -c "import cocotb; print('cocotb', cocotb.__version__)"
```

### Task 2: macOS setup script

**Files:**
- Create: `.github/scripts/setup-macos.sh`

**Interfaces:**
- Produces: PATH-installed ghdl/iverilog/verilator/yosys + cocotb importable by the `macos` job in Task 4.

- [ ] **Step 1: Write the script**

```bash
#!/usr/bin/env bash
# macOS tool env for the tools CI matrix (promised set: ghdl iverilog verilator yosys cocotb).
set -euo pipefail

brew install llvm icarus-verilog verilator yosys

# ghdl is NOT in Homebrew (checked 2026-11-10: no core formula, no tap).
# Use the official llvm-backend build for Apple silicon; needs brew llvm.
GHDL_URL=$(curl -fsSL https://api.github.com/repos/ghdl/ghdl/releases/latest \
  | python3 -c "import json,sys
assets = json.load(sys.stdin)['assets']
print(next(a['browser_download_url'] for a in assets
           if 'llvm' in a['name'] and a['name'].endswith('macos15-aarch64.tar.gz')))")
curl -fsSL -o /tmp/ghdl.tgz "$GHDL_URL"
sudo tar -xzf /tmp/ghdl.tgz -C /usr/local
rm /tmp/ghdl.tgz

# cocotb pinned to the probed version (--break-system-packages is a no-op
# when no EXTERNALLY-MANAGED marker exists).
python3 -m pip install --break-system-packages cocotb==2.1.0

# The promised set must answer, or this script fails the job.
ghdl --version | head -1
iverilog -V 2>&1 | head -1
verilator --version
yosys -V
python3 -c "import cocotb; print('cocotb', cocotb.__version__)"
```

### Task 3: Windows setup script

**Files:**
- Create: `.github/scripts/setup-windows.ps1`

**Interfaces:**
- Produces: PATH-installed ghdl/iverilog/yosys for the `windows` job in Task 4 (via `$env:GITHUB_PATH`, which persists to later steps).

- [ ] **Step 1: Write the script**

```powershell
# Windows tool env for the tools CI matrix (promised set: ghdl iverilog yosys).
# nvc/verilator/cocotb stay WSL/POSIX-only per the README matrix -- their
# gated tests self-skip here, honestly.
$ErrorActionPreference = 'Stop'

# iverilog — the only one of our tools Chocolatey carries (checked 2026-11-10).
choco install iverilog -y --no-progress

# ghdl — official mcode build for Windows (ucrt64), not on Chocolatey.
$ghdl = (Invoke-RestMethod 'https://api.github.com/repos/ghdl/ghdl/releases/latest').assets |
  Where-Object { $_.name -match '^ghdl-mcode-.*-ucrt64\.zip$' } |
  Select-Object -First 1
Invoke-WebRequest $ghdl.browser_download_url -OutFile "$env:RUNNER_TEMP\ghdl.zip"
Expand-Archive "$env:RUNNER_TEMP\ghdl.zip" -DestinationPath "$env:RUNNER_TEMP\ghdl" -Force
"$(Get-ChildItem -Directory "$env:RUNNER_TEMP\ghdl" | Select-Object -First 1 -ExpandProperty FullName)\bin" |
  Add-Content $env:GITHUB_PATH

# yosys — OSS CAD Suite is the official Windows distribution (no choco package).
$oss = (Invoke-RestMethod 'https://api.github.com/repos/YosysHQ/oss-cad-suite-build/releases/latest').assets |
  Where-Object { $_.name -match '^oss-cad-suite-windows-x64-.*\.tgz$' } |
  Select-Object -First 1
Invoke-WebRequest $oss.browser_download_url -OutFile "$env:RUNNER_TEMP\oss-cad-suite.tgz"
tar -xzf "$env:RUNNER_TEMP\oss-cad-suite.tgz" -C "$env:RUNNER_TEMP"
"$env:RUNNER_TEMP\oss-cad-suite\bin" | Add-Content $env:GITHUB_PATH

# The promised set must answer on THIS step's PATH, or the script fails
# (the same directories just written to GITHUB_PATH, applied locally).
$env:PATH = "$env:RUNNER_TEMP\ghdl\$(Get-ChildItem -Directory "$env:RUNNER_TEMP\ghdl" | Select-Object -First 1 -ExpandProperty Name)\bin;$env:RUNNER_TEMP\oss-cad-suite\bin;$env:PATH"
ghdl --version | Select-Object -First 1
iverilog -V 2>&1 | Select-Object -First 1
yosys -V
```

### Task 4: the tools.yml workflow

**Files:**
- Create: `.github/workflows/tools.yml`

**Interfaces:**
- Consumes: the image (Task 1) by name `ghcr.io/nabilmerk/orbit-drives-ci-linux:latest`; the scripts (Tasks 2–3) by path.

- [ ] **Step 1: Write the workflow**

```yaml
name: tools

on:
  push:
    branches: [main]
    paths:
      - 'src/**'
      - 'tests/**'
      - 'Cargo.toml'
      - '.github/workflows/tools.yml'
      - '.github/docker/**'
      - '.github/scripts/**'
  pull_request:
    branches: [main]
    paths:
      - 'src/**'
      - 'tests/**'
      - 'Cargo.toml'
      - '.github/workflows/tools.yml'
      - '.github/docker/**'
      - '.github/scripts/**'
  schedule:
    - cron: '0 6 * * 1' # Mondays 06:00 UTC — the rot detector re-probes every tool
  workflow_dispatch:

concurrency:
  group: tools-${{ github.ref }}
  cancel-in-progress: true

permissions:
  contents: read
  packages: write

jobs:
  image:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: docker/login-action@v3
        with:
          registry: ghcr.io
          username: ${{ github.actor }}
          password: ${{ secrets.GITHUB_TOKEN }}
      - uses: docker/build-push-action@v6
        with:
          context: .github/docker
          file: .github/docker/linux.Dockerfile
          push: ${{ github.event_name != 'pull_request' }}
          tags: |
            ghcr.io/nabilmerk/orbit-drives-ci-linux:latest
            ghcr.io/nabilmerk/orbit-drives-ci-linux:${{ github.sha }}
          cache-from: type=gha
          cache-to: type=gha,mode=max

  linux:
    needs: image
    runs-on: ubuntu-latest
    container:
      image: ghcr.io/nabilmerk/orbit-drives-ci-linux:latest
    steps:
      - uses: actions/checkout@v4
      - uses: dtolnay/rust-toolchain@stable
      - name: Assert the promised set
        run: |
          ghdl --version | head -1
          nvc --version | head -1
          iverilog -V 2>&1 | head -1
          verilator --version
          yosys -V
          python3 -c "import cocotb; print('cocotb', cocotb.__version__)"
      - run: cargo test

  windows:
    runs-on: windows-latest
    timeout-minutes: 60
    steps:
      - uses: actions/checkout@v4
      - name: Install the promised set
        shell: pwsh
        run: ./.github/scripts/setup-windows.ps1
      - uses: dtolnay/rust-toolchain@stable
      - run: cargo test

  macos:
    runs-on: macos-latest
    timeout-minutes: 45
    steps:
      - uses: actions/checkout@v4
      - run: bash .github/scripts/setup-macos.sh
      - uses: dtolnay/rust-toolchain@stable
      - run: cargo test
```
